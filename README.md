# ธรรมะคลายใจ — สุ่มคำสอนครูบาอาจารย์ตามเรื่องที่อยู่ในใจ

พิมพ์ปัญหา (หรือแตะเลือกหัวข้อ) → หายใจเข้า 4 วิ · ออก 5 วิ ตามวงทอง 3 รอบ → ได้คำสอน 1 ชิ้นที่ตรงกับเรื่องนั้น
กด "สุ่มอีกครั้ง" เพื่อรับคำสอนชิ้นใหม่ในเรื่องเดิม (ระบบเลี่ยงชิ้นที่เพิ่งเห็นแล้ว)

## เปิดใช้
- เล่นออนไลน์: https://saengkade.github.io/dhamma-klai-jai/
- ดับเบิลคลิก `index.html` ได้เลย (ทำงานแบบออฟไลน์ได้ ยกเว้นฟอนต์ Google ที่ต้องใช้เน็ต)
- หรือเอาทั้งโฟลเดอร์ไปวางบนเว็บโฮสต์แบบ static ใดก็ได้ (GitHub Pages, Netlify, Cloudflare Pages)

การ์ดหลวงปู่แสดงเป็นรูปต้นฉบับ (ไม่ได้พิมพ์ข้อความใหม่ เพื่อไม่ให้คลาดเคลื่อน) ใบที่ซ้ำกัน ใบประชาสัมพันธ์ และใบอวยพร ถูกตัดออก

## วิธีจับคู่
- `tools/topics.json` คือพจนานุกรม 18 หัวข้อ (เครียด, เงิน, ครอบครัว, โกรธ, ท้อ, …) มีทั้งคำที่พบในคำสอน (`terms`) และคำที่คนมักพิมพ์ (`q`)
- ตอนสร้างข้อมูล คำสอนแต่ละชิ้นจะได้แท็กหัวข้อจากคำที่ปรากฏ (คำสอนยายได้คะแนนเพิ่มจากหมวดเดิมด้วย) การ์ดหลวงปู่ติดแท็กด้วยมือ
- ตอนใช้งาน ข้อความที่พิมพ์ → หาหัวข้อ + คำที่ตรงกัน → คัดคำสอนที่เข้ากันได้มากที่สุดจากทั้ง 3 แหล่ง แล้ว**สุ่มถ่วงน้ำหนัก** 1 ชิ้น
- ถ้าข้อความส่อว่าคิดทำร้ายตัวเอง แอพจะแสดงสายด่วน 1323 / 1669 และเลือกคำสอนให้กำลังใจ (ไม่ส่งคำสอนเรื่องความตาย)

## ปรับแต่ง
- จังหวะหายใจ: `BREATH` บรรทัดบนสุดของ `app.js`
- เพิ่ม/แก้คำในหัวข้อ: แก้ `tools/topics.json` แล้วรัน `python3 -I tools/build_data.py` (สร้าง `data.js` ใหม่)
- เพิ่มคำสอน: เพิ่มรายการใน `sources/*.json` แล้วรันคำสั่งเดียวกัน
